Use Patch to add lights from the type list (moving spots, washes and beams, profiles, Fresnels and LED PARs) to any truss, change the type of selected lights, or remove them. Select lights by clicking their tags on the stage, rows in the fixture sheet, or a group. Turn the encoders (drag up and down, scroll, or use arrow keys) to set dimmer, pan, tilt, zoom and color. Use Aim and click the stage to point the selected lights at that spot. Press Store to save the look as a new cue, then Go and Back to play the cue list. The command line accepts console syntax such as Group 2 At 80, 101 Thru 103 @ Full, Store Cue 6 and Cue 3.

From first read-through to opening night

A typical mid-scale play runs ten to twelve weeks from first meeting to opening night. We join as early as the set designer's first model box.

  1. 01

    Read & concept

    Script breakdown, references and a lighting storyboard agreed with the director and set designer.

    Weeks 1–2
  2. 02

    Previs model

    We build the venue, set and masking from the CAD files, using the house's rep plot as the starting rig.

    Weeks 2–4
  3. 03

    Plot & paperwork

    The light plot and hookup go to the production electrician and rental shop for pricing.

    Weeks 4–6
  4. 04

    Offline programming

    We write the cue stack against the model and show it to the director in a previs session.

    Weeks 6–9
  5. 05

    Load-in & focus

    Hang, focus with our focus charts and check the patch against the model.

    Week 10
  6. 06

    Tech & previews

    We refine cues in the room, give notes each preview and freeze the show at opening.

    Weeks 11–12
